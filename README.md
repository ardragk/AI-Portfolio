# AI and Machine Learning Portfolio

Academic projects completed as part of my Postgraduate Program in Artificial Intelligence and Machine Learning.

## Projects

### 1. Employee Promotion Prediction
Analyzed employee data and built classification models to predict promotion outcomes.
**Tools:** Python, Pandas, Scikit-learn, XGBoost, SMOTE

### 2. ReneWind — Wind Turbine Failure Prediction
Used turbine sensor data and neural networks to identify patterns associated with generator failure.
**Tools:** Python, TensorFlow, Keras, neural networks

### 3. Medical Knowledge Assistant
Built an educational RAG prototype that retrieves information from medical reference documents to support grounded question answering. It is not a clinical diagnostic tool.
**Tools:** Python, LangChain, Chroma, SentenceTransformers, PyMuPDF, local LLM

### 4. SuperKart — Retail Sales Forecasting
Prepared retail data, compared forecasting models, and built prediction workflows. The project is in a separate repository: [SuperKart Sales Predictor](https://github.com/ardragk/superkart_sales_predictor-rest-api).
**Tools:** Python, Scikit-learn, Random Forest, Flask, Streamlit

### 5. HelmNet — Safety Helmet Detection
Trained image-classification models to identify whether workers were wearing safety helmets.
**Tools:** Python, TensorFlow, Keras, CNN, VGG16, OpenCV

### 6. AllLife Bank — Personal Loan Prediction
Analyzed customer data and built decision-tree models to estimate personal-loan acceptance.
**Tools:** Python, Pandas, decision trees, GridSearchCV

### 7. FoodHub — Restaurant Order Analysis
Explored restaurant delivery orders and visualized customer, cuisine, and delivery-time patterns.
**Tools:** Python, Pandas, NumPy, Matplotlib, Seaborn
