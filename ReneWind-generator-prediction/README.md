# ReneWind Generator Prediction

## Problem Statement
Predict generator failures in wind turbines using machine learning techniques.

## Business Context
Renewable energy companies use predictive maintenance to identify equipment failures before they occur, reducing downtime and maintenance costs.

## Objective
Build classification models to predict generator failures and identify the best-performing model.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn

## Machine Learning Models
- Logistic Regression
- Decision Tree
- Random Forest

## Project Files
- INN_ReneWind_Main_Project_FullCode_Notebook.ipynb

## Outcome
Developed and evaluated multiple classification models to support predictive maintenance decisions.
